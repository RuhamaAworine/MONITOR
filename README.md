# MONITOR — Stress Detection System
MONITOR is a machine learning project that detects human stress levels using physiological signals and questionnaire data

## Project Goal
To predict stress levels using:
- Heart Rate (HR)
- GSR (Galvanic Skin Response)
- Temperature
- Questionnaire data

## Features
- Data preprocessing
- Baseline comparison
- Feature engineering
- Machine learning model training
- Performance evaluation (MAE, R²)
